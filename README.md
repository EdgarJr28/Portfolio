# Portfolio Website

Welcome to my personal portfolio website! Built with the latest version of Next.js, this site showcases my skills, projects, and professional journey. It features a modern, responsive design and includes dynamic content that highlights my expertise in web development, user experience design, and interface design.

## Features

- **Next.js**: Leveraging the powerful features of Next.js for server-side rendering, static site generation, and API routes.
- **Responsive Design**: Ensuring a seamless experience across all devices, from mobile phones to desktop computers.
- **Dynamic Content**: Integrating dynamic and interactive elements to engage visitors and showcase projects effectively.
- **Modern UI/UX**: Using Tailwind CSS for a sleek and modern interface, with attention to user experience and accessibility.
- **Animation and Interactivity**: Adding subtle animations and hover effects to enhance the user experience.
- **SEO Optimized**: Implementing best practices for search engine optimization to improve visibility and reach.

## Technologies Used

- **Next.js**: The React framework for production.
- **React**: Building reusable and dynamic components.
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
- **FontAwesome**: Icons for enhancing visual appeal and usability.
- **TypeScript**: Adding static typing to JavaScript for improved developer experience and code quality.

## Installation and Setup

To run this project locally, follow these steps:

1. **Clone the repository**:
    ```sh
    git clone https://github.com/EdgarJr28/Portfolio.git
    ```
2. **Navigate to the project directory**:
    ```sh
    cd portfolio
    ```
3. **Install dependencies**:
    ```sh
    npm install
    ```
4. **Run the development server**:
    ```sh
    npm run dev
    ```
5. **Open your browser** and visit `http://localhost:3000` to see the website in action.
